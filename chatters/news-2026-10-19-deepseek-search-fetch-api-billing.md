DeepSeek 官宣 API 开放自研网页搜索与抓取能力：Search 返回带标题、摘要、时效与权威指标的结构化结果，Fetch 直接把目标页面转成 Markdown，定价每 1000 次成功请求 5 元，失败和空结果不计费。通过 DeepSeek Harness、Claude Code、Codex 等服务端工具调用目前免费，11 月 1 日起开始按次计费，消息在 Hacker News 上拿下 479 个赞。

**为什么值得看**：模型厂商开始把联网查资料做成明码标价的一等公民，下一代 Agent 的竞争力可能不在脑子，而在采购渠道。
