Cloudflare 开源的 security-audit-skill 本月拿下约 2.2 万星，登顶 GitHub 月度趋势榜。它是一个给编码智能体用的安全审计技能：把多阶段安全审计拆成标准化流程，让 Claude Code 这类 Agent 按步骤扫描代码库，并输出可独立核验的机器可读审计结论。同一时间榜单前十几乎被 Agent 周边工具包圆，安全这条竖切赛道是其中最硬的。

**为什么值得看**：大厂开始把内部安全实践直接封装成 Agent 技能开源，代码审计这件事正在从人工渗透测试的奢侈品变成每个人终端里的标配。
