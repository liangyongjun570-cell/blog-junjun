OpenAI 官宣 Decisions API 正式全面可用：基于 GPT-6 Luna 构建，专门处理应用里高频的小型决策——分类、路由、打分，速度比标准调用快最多 10 倍，输入价格每百万 token 只要 0.1 美元且不收输出费。Box、Datadog、Ramp 等客户实测延迟降低了 3 到 40 倍。

**为什么值得看**：AI 应用的下一层基础设施不是更大的模型，而是更便宜更快的"拍脑袋"专用件。
