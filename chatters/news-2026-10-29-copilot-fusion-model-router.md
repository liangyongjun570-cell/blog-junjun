GitHub Universe 2026 上纳德拉发布 Copilot Fusion——一个多模型编排系统，开发者只需选 Standard、High 或 Max 三档力度，系统自动在 Anthropic 和 OpenAI 模型间路由、升级和互评。官方称 Fusion Max 在 Artificial Analysis 编码智能体指数上以 60 分反超 Claude Code 的 58 分，速度快 40%，成本最高降 77%。企业版同时改为积分制，所有 Copilot 功能不再单独订阅。

**为什么值得看**：模型层卷完开始卷编排层，"帮你省钱的路由器"成了新的护城河——当然，成绩先当厂商自卖自夸听。
