GitHub AI Agent 生态最新统计显示，openclaw 以 39.24 万星位居 AI Agent 类项目榜首，AI 逆向工具 rea 单日暴涨 1.54 万星成为增长最快项目。榜单背后是清晰的分层趋势：入口层的 opencode、记忆层的 agentmemory、编排层的 ruflo 各占一个生态位，还有面向智能体技能注册与权限审计的 skillhub 类项目冒头。纯大模型底座项目热度退潮，Agent 的记忆、技能、权限管理成为新战场。

**为什么值得看**：当 Agent 从单个玩具变成一支舰队，版本管理、权限控制和审计日志这些「无聊」的基础设施，恰恰是下一个百星仓库的孵化地。
