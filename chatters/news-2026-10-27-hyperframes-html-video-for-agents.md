GitHub 本周热榜出现 heygen-com 组织的 hyperframes 项目，口号是"写 HTML，渲染视频，为 Agent 而生"，总星数已冲破 7 万、单日涨星六千多。它的思路是把视频合成拆成 HTML 和 CSS 时间轴，AI Agent 生成网页就等于生成可编程视频，天然适配 Claude Code、Codex 这类以写代码见长的编程智能体。

**为什么值得看**：视频生成赛道还在卷模型算力，这个项目直接换赛道，用程序员最熟悉的 HTML 当视频描述语言，React 视频库 Remotion 迎来最有力的挑战者。

🔗 [GitHub 仓库](https://github.com/heygen-com/hyperframes)
