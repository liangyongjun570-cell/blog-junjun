title: "Anthropic 把 Agent Skills 标准捐给了 Linux 基金会"
date: "2026-10-23"
tags: ["开源项目"]
mood: 📡 情报站
---
Anthropic 宣布将 Agent Skills 开放标准捐赠给 Linux 基金会旗下的 Agentic AI Foundation，连同名称、标志、GitHub 组织和 agentskills.io 域名一并移交。该标准自去年 12 月发布以来已被 ChatGPT、Cursor、GitHub Copilot 等 70 多个平台集成，公开技能约 100 万个，累计安装近 2.8 亿次。这也是继 MCP 之后，Anthropic 捐给 AAIF 的第二项标准。

**为什么值得看**：智能体的"技能包"正在变成 USB 接口式的通用标准，把规则交给社区的厂商，往往比圈地自萌的走得更远。
