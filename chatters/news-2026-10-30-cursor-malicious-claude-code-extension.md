据 The Verge 报道，AI 编程工具 Cursor 官方通报约 5000 人可能安装了一个恶意版 Claude Code 扩展，该扩展于周四早晨出现在其扩展市场，会在用户机器上收集主机名、用户名、系统目录路径和公网 IP 等信息。Cursor 已公布受影响的时间窗口，并提醒用户检查与移除相关插件。

**为什么值得看**：AI 编程工具的插件生态正在成为供应链攻击的新温床，装扩展前先看发布者这个老习惯关键时刻真能救命。
