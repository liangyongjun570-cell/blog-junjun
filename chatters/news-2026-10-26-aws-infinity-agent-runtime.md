AWS 本周开源了 Infinity，一个专为海量并发 Agent 设计的运行时。传统 Agent 框架在等待 20 分钟构建、等 PR 合并、等隔夜审批时也在空转占用资源，Infinity 则让绝大多数时间处于等待态的 Agent 能被极高密度地挂起和调度。

**为什么值得看**：当 Agent 大军成为常态，"等待"才是 Agent 生命周期的主旋律，这块基础设施空白被巨头抢先填上了。
